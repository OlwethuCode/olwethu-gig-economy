# The Gig Economy — Olwethuthando

A polished, three-page Flask website exploring opportunities, challenges and digital skills in the changing world of work.

## Run locally

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000 in your browser.

## Pages

- **Home** — project overview, focus question, purpose, method and abstract.
- **Research & Findings** — research context, transparent simulated questionnaire results, visual summaries and references.
- **Career Focus** — freelance graphic design, digital skills, tools, project workflow and Fiverr account-safety notes.

The 20 questionnaire records and all displayed percentages are simulated demonstration data, not findings from real participants.
